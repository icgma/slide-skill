# Rendering Style: 3D Render

**Description:** Photorealistic 3D renders with soft lighting and reflections

**Best for:** Product showcases, tech demos, concept visualization

## Prompt Prefix

```
3D render, soft studio lighting, subtle reflections, smooth surfaces, photorealistic
```

## Usage

Prepend this prefix to your image generation prompt to achieve the `3d-render` rendering style.
Combine with a palette from `image-palettes/` for consistent results.
