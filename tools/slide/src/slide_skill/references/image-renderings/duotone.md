# Rendering Style: Duotone

**Description:** Two-color high contrast treatment

**Best for:** Bold statements, social media, marketing, posters

## Prompt Prefix

```
duotone style, two-color palette, high contrast, graphic poster style, bold
```

## Usage

Prepend this prefix to your image generation prompt to achieve the `duotone` rendering style.
Combine with a palette from `image-palettes/` for consistent results.
