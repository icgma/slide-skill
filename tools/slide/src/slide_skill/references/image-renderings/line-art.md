# Rendering Style: Line Art

**Description:** Clean line drawings with minimal fills

**Best for:** Technical docs, patents, minimalist design, sketches

## Prompt Prefix

```
line art, thin clean strokes, black and white, technical drawing, blueprint style
```

## Usage

Prepend this prefix to your image generation prompt to achieve the `line-art` rendering style.
Combine with a palette from `image-palettes/` for consistent results.
