# Rendering Style: Gradient Abstract

**Description:** Smooth color gradients with organic abstract shapes

**Best for:** Backgrounds, mood setting, breathing slides, atmospheric

## Prompt Prefix

```
abstract gradient, smooth color transitions, organic shapes, flowing forms, ambient
```

## Usage

Prepend this prefix to your image generation prompt to achieve the `gradient-abstract` rendering style.
Combine with a palette from `image-palettes/` for consistent results.
