# Rendering Style: Photographic

**Description:** Natural photography with realistic lighting

**Best for:** Case studies, real-world examples, team photos, locations

## Prompt Prefix

```
photorealistic, natural lighting, high resolution, authentic, candid style
```

## Usage

Prepend this prefix to your image generation prompt to achieve the `photographic` rendering style.
Combine with a palette from `image-palettes/` for consistent results.
