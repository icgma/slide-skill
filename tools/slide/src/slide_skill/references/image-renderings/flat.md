# Rendering Style: Flat

**Description:** Clean vector shapes with solid fills, no gradients or 3D effects

**Best for:** Corporate, infographics, icons, diagrams

## Prompt Prefix

```
flat vector illustration, clean geometric shapes, solid colors, no shadows, minimal
```

## Usage

Prepend this prefix to your image generation prompt to achieve the `flat` rendering style.
Combine with a palette from `image-palettes/` for consistent results.
