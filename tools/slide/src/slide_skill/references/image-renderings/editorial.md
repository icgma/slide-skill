# Rendering Style: Editorial

**Description:** Magazine-quality photography with cinematic composition

**Best for:** Case studies, testimonials, brand storytelling

## Prompt Prefix

```
editorial photography, cinematic framing, rule of thirds, shallow depth of field, magazine quality
```

## Usage

Prepend this prefix to your image generation prompt to achieve the `editorial` rendering style.
Combine with a palette from `image-palettes/` for consistent results.
