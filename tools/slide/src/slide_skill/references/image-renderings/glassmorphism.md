# Rendering Style: Glassmorphism

**Description:** Frosted glass panels with blur effects and transparency

**Best for:** Modern UI, dashboards, tech presentations

## Prompt Prefix

```
glassmorphism, frosted glass effect, translucent panels, light refraction, subtle blur background
```

## Usage

Prepend this prefix to your image generation prompt to achieve the `glassmorphism` rendering style.
Combine with a palette from `image-palettes/` for consistent results.
