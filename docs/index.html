30 秒上手

挑一个模板,填上标题,剩下的交给 SVG 渲染管线。

~/my-deck — zsh 
# 看全部 80 个模板
slide-skill templates

# 钻入某个分类
slide-skill templates --category business

# 看某模板的配方(主题 / 布局序列 / 示例提纲)
slide-skill templates --show biz-mck-strategy

# 一行生成项目骨架,自动套主题、写好示例提纲
slide-skill template-quickstart biz-mck-strategy --title "我的战略复盘"

# 把骨架变成 PPTX
slide-skill svg          projects/biz-mck-strategy --source ...
slide-skill finalize-svg projects/biz-mck-strategy
slide-skill export       projects/biz-mck-strategy
# → projects/biz-mck-strategy/exports/biz-mck-strategy_*.pptx ✓
