# Python基础入门

## 变量与数据类型

- **整数 (int)** — age = 25
- **浮点数 (float)** — price = 19.99
- **字符串 (str)** — name = "Alice"
- **布尔值 (bool)** — is_student = True

## 条件语句

使用 if-elif-else 结构进行条件判断。注意缩进是Python语法的核心部分。

## 循环

- **for循环** — 遍历序列中的每个元素
- **while循环** — 满足条件时持续执行
- **range()函数** — 生成数字序列

## 函数定义

使用 def 关键字定义函数。函数是可重用的代码块，接受参数并返回结果。

## 列表与字典

列表 (list) 是有序的元素集合，字典 (dict) 是键值对的集合。它们是Python最常用的数据结构。

## 文件操作

使用 open() 函数打开文件，with语句确保文件正确关闭。支持读取、写入和追加模式。

## 总结

掌握变量、条件、循环、函数、数据结构和文件操作，就具备了Python编程的基础能力。
