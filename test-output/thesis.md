# 基于深度学习的医学影像诊断

## 研究目的
- 探索卷积神经网络在胸部CT影像中的病灶检测能力
- 构建多尺度特征融合模型提升小病灶识别率
- 在三甲医院临床数据上验证模型泛化性能

## 方法与模型
- 骨干网络：ResNet-50 + FPN 多尺度特征金字塔
- 检测头：Deformable DETR 自适应注意力机制
- 损失函数：Focal Loss + Dice Loss 联合优化
- 数据增强：MixUp + Mosaic + 随机仿射变换

## 实验结果
- 敏感度：94.7%
- 特异度：96.2%
- AUC：0.972
- F1-Score：0.938

## 与基线方法对比
- RetinaNet：AUC 0.912，提升 6.6%
- YOLOv8：AUC 0.935，提升 3.9%
- Faster R-CNN：AUC 0.928，提升 4.7%
- UNet++：AUC 0.941，提升 3.3%

## 结论与展望
- 多尺度特征融合显著提升小病灶检测能力
- Deformable Attention 有效聚焦病灶区域
- 下一步：引入时序信息实现病灶动态追踪
