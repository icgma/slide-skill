# 推导过程

1、设 y = f(u),u = g(x),则 y = f(g(x))
2、自变量 x 微小变化 Δx,导致 u 变化 Δu = g'(x)Δx
3、u 的变化进一步导致 y 变化 Δy ≈ f'(u)Δu
4、合并两步,得 Δy ≈ f'(g(x)) · g'(x) · Δx
5、取极限得 dy/dx = f'(g(x)) · g'(x)

# 经典例题

- 例 1:y = sin(2x + 1) → dy/dx = 2cos(2x + 1)
- 例 2:y = (3x² + 1)⁵ → dy/dx = 30x(3x² + 1)⁴
- 例 3:y = e^(-x²) → dy/dx = -2x · e^(-x²)
- 例 4:y = ln(1 + x²) → dy/dx = 2x / (1 + x²)
- 例 5:复合三层 y = sin(ln(x²+1)) → 自行展开

# 数值验证

- 取 y = (2x+1)³,x = 1
- 链式法则:dy/dx = 3(2x+1)² · 2 = 6 · 9 = 54
- 数值差分(Δx=0.001):差值 / Δx ≈ 54.012
- 误差 0.02%,验证公式正确
- 提示:数值法适合检验解析解,不适合代替
