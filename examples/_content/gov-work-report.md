# 2025 年度工作总结暨 2026 年工作部署

# 指导思想

> 以高质量发展为主线,坚持稳中求进,持续优化营商环境,服务好辖区企业与群众。

# 主要成绩

- 地区生产总值 GDP 同比增长 6.8%,超额完成年度目标
- 规上工业企业新增 142 家,累计达到 2380 家
- 财政一般公共预算收入 286 亿元,增长 9.4%
- 居民人均可支配收入 5.2 万元,城乡差距缩小至 1.78
- 民生投入占财政支出 78%,十大民生实事全部办结

# 关键数据

- 新增市场主体 4.6 万户,日均诞生 126 户
- 高新技术企业数量 1860 家,较上年 +18%
- 规上服务业营业收入突破千亿,增速 12.3%
- 全社会研发投入强度达到 3.5%,创历史新高
- 城镇调查失业率年均 4.2%,低于年度目标

# 经验做法

1、坚持党建引领,锤炼一支能打硬仗的干部队伍
2、深化"放管服"改革,审批事项压减 42%
3、构建"亲清"政商关系,设立企业服务专员制度
4、用好数字技术赋能基层治理,网格事件办结率 98.6%
5、注重民生兜底,医保 + 教育 + 养老三张网越织越密

# 存在问题

- 县域之间发展不平衡,南北差距仍较明显
- 战略性新兴产业集群尚未形成全国影响力
- 高层次人才引育与发达城市相比仍有差距
- 部分历史遗留信访问题化解周期偏长
- 基层干部承担的属地责任与权限不匹配

# 下阶段安排

- 抓项目:全年开工亿元以上项目 320 个,确保投资增长 12%
- 育产业:重点培育新材料、生物医药、人工智能三大集群
- 优环境:迭代营商环境 6.0 版,打造市场化法治化国际化标杆
- 惠民生:十大民生实事再升级,重点解决"一老一小"
- 强治理:推进市域社会治理现代化试点,确保安全稳定
