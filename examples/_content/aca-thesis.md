# 毕业论文答辩 · 基于多模态融合的医疗影像辅助诊断研究

# 选题背景

- 全球放射科医师缺口超过 20 万,中国基层尤其突出
- 单模态深度学习模型在跨中心场景下泛化不足
- 多模态(影像 + 文本 + 结构化数据)融合是下一个突破口
- 临床落地要求模型可解释、可追溯
- 国家"十四五"明确支持医工交叉研究

# 研究问题

> 如何在标注稀缺场景下,构建可解释的多模态医疗影像诊断模型?

# 方法与数据

1、数据收集:三家三甲医院 8.6 万例胸部 CT + 报告
2、预处理:标准化窗宽窗位 + 文本结构化抽取
3、模型设计:跨模态对比学习 + 弱监督引导
4、可解释模块:基于注意力的病灶可视化
5、评估方案:三家医院交叉验证 + 临床医师双盲评审

# 核心创新点

- 创新一:跨中心一致性约束损失函数(CCC-Loss)
- 创新二:文本-影像对齐的弱监督预训练范式
- 创新三:面向临床的多粒度可解释输出
- 创新四:小样本微调框架,新病种 50 例即可达 90% 准确率
- 创新五:开源工具链 MedFuseKit,已被 7 家机构使用

# 实验结果 vs 现有方法

| 方法 | 指标 |
| ResNet50 单模态 | AUC 0.842,跨中心下降至 0.74 |
| CLIP 通用预训练 | AUC 0.871,但可解释性弱 |
| 我们的 MedFuse | AUC 0.927,跨中心保持 0.91 |
| MedFuse + 临床后处理 | 假阳性率降低 37% |
