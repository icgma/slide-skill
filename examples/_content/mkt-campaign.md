# 「春日新生」整合营销方案

# 市场洞察

- Z 世代将"春天"重新定义为情绪修复期
- 小红书 "春日穿搭" 笔记同比 +186%
- 用户对"治愈系"内容的停留时长比促销内容高 3.2 倍
- 线下快闪体验成为转化的关键节点
- 78% 的购买决策来自朋友推荐,而非品牌广告

# 策略主张

> 不卖产品,卖一段属于自己的春天。

# 创意核心

1、一个主视觉:漫画风格的"春日女孩",可二创
2、三支短片:通勤、毕业、约会三种春日时刻
3、五位品牌挚友:生活方式 KOL 真实分享
4、十城快闪:门店改造为"春日邮局"
5、UGC 互动:用户上传"我的春日瞬间"赢取奖品

# 渠道矩阵

| 渠道 | 角色定位 |
| 小红书 | 主战场,种草 + 话题 + KOC 矩阵 |
| 抖音 | 短片首发与挑战赛 |
| 微博 | 话题引爆与媒体扩散 |
| 线下快闪 | 体验转化与口碑沉淀 |
| 私域社群 | 老客复购与 UGC 收集 |

# 投入预算与 ROI

- 总预算 1800 万元,执行周期 8 周
- KOL 与内容制作 45%,占 810 万元
- 线下快闪 30%,占 540 万元
- 媒介投放 20%,占 360 万元
- 备用 5%,90 万元
- 预期销售拉动 1.2 亿元,ROI 6.7

# 效果预测

- 全网曝光 8 亿次以上
- 品牌搜索量提升 240%
- 新客占比目标 60%
- 复购率较去年同期 +18 pct
- 沉淀 UGC 内容 5 万条以上
