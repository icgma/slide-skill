# 大型推理服务的成本之战 · QCon 2026

# 演讲主题

> 把每一次推理调用,从 0.012 美元降到 0.0006 美元的两年。

# 我们的痛点

- 推理流量两年增长 87 倍,GPU 账单占成本 64%
- 高峰期 P99 延迟突破 1.8 秒,影响用户体验
- 长尾模型种类超过 200 个,资源利用率不足 18%
- 多云部署带来 30% 的额外网络出口成本
- 黑五等突发流量难以预测,容量规划永远滞后

# 核心数据

- 单次推理成本下降 95%,从 1.2 分到 0.06 分
- GPU 平均利用率从 18% 提升到 71%
- P99 延迟从 1820 ms 降到 380 ms
- 模型加载时间从 90 秒压缩到 3 秒
- 容量弹性窗口从 30 分钟缩短到 90 秒

# 我们的解法

1、统一推理网关:KV-Cache 跨请求复用,命中率 64%
2、混合精度调度:fp16 / int8 / int4 按 SLA 智能切换
3、推理优化器:TVM + TensorRT 双后端自动选优
4、Spot + 预留混合调度:成本最优容量曲线
5、流量预测:基于业务事件的 7 日滚动预测,误差 8%

| 我们的混合架构 | 0.0006 美元,跨 3 朵云 |

# 经验沉淀

> 真正省钱的不是更便宜的硬件,而是把每一比特带宽与显存都用满的工程纪律。
