# Python 入门速览

## 什么是 Python

Python 是一门简洁、易读的编程语言，广泛应用于数据科学、Web 开发和自动化。

- 语法接近自然语言，适合零基础入门
- 拥有庞大的第三方库生态
- 社区活跃，学习资源丰富

## 变量与数据类型

Python 不需要声明变量类型，直接赋值即可：

- **整数** `int`：如 `age = 20`
- **浮点数** `float`：如 `price = 9.99`
- **字符串** `str`：如 `name = "Alice"`
- **布尔** `bool`：如 `is_student = True`

动态类型让代码更简洁，但也需要注意类型错误。

## 条件与循环

控制程序流程的两种核心结构：

- **if/elif/else**：根据条件执行不同代码块
- **for 循环**：遍历列表、字符串、range 等可迭代对象
- **while 循环**：条件为真时持续执行

缩进是 Python 语法的一部分，用 4 个空格表示代码块层级。

## 函数

用 `def` 定义函数，封装可复用的逻辑：

- 函数可以有参数和返回值
- 支持默认参数和关键字参数
- 用 `lambda` 创建简单的匿名函数

好的函数命名和文档字符串能让代码更易维护。

## 列表推导式

Python 的标志性语法糖，一行代码替代多行循环：

- `[x * 2 for x in range(10)]` 生成偶数列表
- `[x for x in nums if x > 0]` 过滤正数
- 可以嵌套，但建议保持简洁

掌握列表推导式是写出 Pythonic 代码的关键一步。
