# Phase 25: Dual-Artifact Export & Pipeline Polish — Plan

## Goal

实现双产物导出和管线整体打磨，使交付物兼顾编辑性和可分享性

## Requirements Covered

DAE-01, DAE-02, DAE-03, DAE-04

## Tasks

### Task 1: 预览版 PPTX 导出 — preview_pptx.py [DAE-01, DAE-02]

**Files:** `tools/slide/src/slide_skill/preview_pptx.py` (new)

**What:**
- `export_preview_pptx(project_path, output=None, stage="final")` → 生成 SVG-as-image 预览版 PPTX
- 每页：将 SVG 文件渲染为 PNG（通过 cairosvg 或 Pillow SVG），嵌入为图片
- 如果渲染不可用，将 SVG 原文嵌入为图片描述（降级）
- 使用 python-pptx 的 slide.shapes.add_picture() 添加每页图片
- 输出到 backup/<timestamp>/ 目录

**Verification:** 单元测试覆盖预览版生成、降级处理

### Task 2: 双产物导出集成到 export_project [DAE-01, DAE-03]

**Files:** `tools/slide/src/slide_skill/exporter.py` (modify)

**What:**
- `export_project()` 新增 `preview=True` 参数（默认生成双产物）
- 原生版存入 `exports/`，预览版存入 `backup/<timestamp>/`
- `_write_backup()` 中调用 `export_preview_pptx()` 生成预览版
- 返回值不变（仍返回原生版路径）

**Verification:** 测试 export_project 默认生成双产物

### Task 3: CLI --preview-only 标志 [DAE-04]

**Files:** `tools/slide/src/slide_skill/cli.py` (modify)

**What:**
- `export` 命令新增 `--preview-only` 标志
- `--preview-only` 时仅生成预览版 PPTX，跳过原生 DrawingML 版
- `quickstart` 管线完整运行：init → confirm → spec → image → svg → check → finalize → export → qa

**Verification:** CLI 测试

### Task 4: SKILL.md + IDE 规则更新

**Files:** `skills/slide/SKILL.md`, `.cursorrules`

**Verification:** 文件包含双产物导出相关内容
