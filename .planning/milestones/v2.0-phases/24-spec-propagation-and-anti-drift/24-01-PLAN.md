# Phase 24: Spec Propagation & Anti-Drift — Plan

## Goal

实现增量设计传播，使迭代设计不再需要全量重生成

## Requirements Covered

SP-01, SP-02, SP-03, SP-04 (AD-01/AD-02 already implemented in Phase 22)

## Tasks

### Task 1: update_spec 模块 — update_spec.py [SP-01, SP-02, SP-03]

**Files:** `tools/slide/src/slide_skill/update_spec.py` (new)

**What:**
- `update_spec(project_path)` → 主函数：读取 spec_lock 差异，传播到 SVG，重跑 QA
- `_extract_palette_diff(old_lock, new_lock)` → 提取 palette 颜色变更映射 {old_hex: new_hex}
- `_extract_font_diff(old_lock, new_lock)` → 提取 font-family 变更 (old, new)
- `_propagate_colors(svg_dir, color_map)` → 在 SVG 文件中替换颜色值
- `_propagate_font(svg_dir, old_font, new_font)` → 在 SVG 文件中替换 font-family
- `_backup_svg_output(project_path)` → 备份 svg_output/ 到 svg_output.bak/
- `UNSUPPORTED_FIELDS` 常量：不可增量传播的字段列表
- `_check_unsupported_changes(old_lock, new_lock)` → 检测不支持的字段变更并报错

**Verification:** 单元测试覆盖颜色传播、字体传播、不支持字段报错、备份

### Task 2: CLI 命令 [SP-01]

**Files:** `tools/slide/src/slide_skill/cli.py` (modify)

**What:**

- 输出传播报告：替换文件数、替换处数、QA 结果

**Verification:** CLI 集成测试

### Task 3: SKILL.md 更新

**Files:** `skills/slide/SKILL.md` (modify)

- 说明传播流程：修改 spec_lock → update-spec → 自动 QA

**Verification:** SKILL.md 包含 update-spec 相关内容
