# Phase 22: Design Gate & Spec Enrichment — Plan

## Goal

实现八确认门控和设计规格丰富化，使管线从"机械生成"升级为"意图驱动"

## Requirements Covered

DG-01, DG-02, DG-03, DSE-01, DSE-02, DSE-03, DSE-04, AD-03

## Tasks

### Task 1: 确认模块 — confirmations.py [DG-01, DG-02, DG-03]

**Files:** `tools/slide/src/slide_skill/confirmations.py` (new), `tools/slide/src/slide_skill/__init__.py` (update)

**What:**
- 创建 `confirmations.py` 模块，定义默认八确认项和确认逻辑
- `DEFAULT_CONFIRMATION_ITEMS` 常量列表：title, audience, key_points, layout_strategy, color_scheme, page_count, special_requirements, confirmation
- `check_confirmations(project_path)` → 验证 `confirmations.json` 存在且所有必需项已确认
- `write_confirmations(project_path, data)` → 写入 `confirmations.json`
- `get_confirmation_items(project_path)` → 返回确认项列表（合并默认 + 竞赛模板扩展）
- 竞赛模板扩展项从 `competition.py` 的 `time_limit` 和 `section_guidance` 映射

**Verification:** 单元测试覆盖：写入/读取/验证完整确认、缺失项检测、竞赛扩展项

### Task 2: 确认 CLI 命令 [DG-01, DG-02, DG-03]

**Files:** `tools/slide/src/slide_skill/cli.py` (modify)

**What:**
- 新增 `check-confirm` 子命令：`slide-skill check-confirm <project>` → 验证确认完整性，输出缺失项
- 新增 `confirm` 子命令：`slide-skill confirm <project> --title X --audience Y ...` → 非交互式批量写入确认（供 agent 调用）
- `--skip-confirm` 标志添加到 `svg` 和 `quickstart` 命令（快速路径跳过确认检查）

**Verification:** CLI 集成测试

### Task 3: 确认门控集成到 generate_svg [DG-01]

**Files:** `tools/slide/src/slide_skill/svg_pipeline.py` (modify)

**What:**
- `generate_svg()` 开头检查 `confirmations.json`（除非 `skip_confirm=True`）
- 无确认时抛出 `RuntimeError` 并列出缺失项
- `_load_or_create_lock()` 中确认完成后从 `confirmations.json` 提取 audience/objective 写入 spec_lock

**Verification:** 测试无确认时拒绝、有确认时允许、`--skip-confirm` 时跳过

### Task 4: SKILL.md 更新 — 确认门控指示 [DG-01, AD-03]

**Files:** `skills/slide/SKILL.md` (modify)

**What:**
- 在 Required Discipline 之前新增 **Design Gate** 章节
- 指示 agent 在 SVG 生成前通过对话收集八确认
- 提供确认项清单和对话模板
- 指示 agent 写入 `confirmations.json` 后再执行 `slide-skill svg`
- 长幅演示（>20 页）逐页重读 spec_lock 的指示（AD-03）
- Quick Reference 表新增 `check-confirm` 命令

**Verification:** SKILL.md 包含 Design Gate 章节、八确认清单、确认流程指示

### Task 5: design_spec.md 丰富化 [DSE-01, DSE-02, DSE-04]

**Files:** `tools/slide/src/slide_skill/svg_pipeline.py` (modify `create_spec`)

**What:**
- `create_spec()` 扩展 `design_spec.md` 模板，新增章节：
  - `## Audience & Objective` — audience, objective 字段
  - `## Visual Strategy` — overall_visual_strategy, tone
  - `## Per-Page Design Intent` — 逐页 key_message, design_rationale, visual_strategy, reference_style
- 竞赛模板自动填充 audience/objective（从 competition.py 的 section_guidance 和 time_limit）
- `create_spec()` 接受可选参数 `confirmations: dict` 从确认数据填充 audience/objective

**Verification:** 生成 design_spec.md 包含新章节、竞赛模板自动填充

### Task 6: spec_lock.json 新增字段 [DSE-03]

**Files:** `tools/slide/src/slide_skill/svg_pipeline.py` (modify `create_spec`)

**What:**
- `spec_lock` 新增 `audience`、`objective`、`per_page_rationale` 字段
- `per_page_rationale` 结构：`{"slide_01": {"key_message": "...", "design_rationale": "..."}}`
- 从 `confirmations.json` 读取 audience/objective 填入 spec_lock
- 保留向后兼容：旧 spec_lock 无新字段时不报错

**Verification:** spec_lock.json 包含新字段、向后兼容

### Task 7: 逐页 spec_lock 重读 [AD-01, AD-02]

**Files:** `tools/slide/src/slide_skill/svg_pipeline.py` (modify `generate_svg`)

**What:**
- `generate_svg()` 循环内每页前重新读取 `spec_lock.json`
- 比对关键值（palette 主色、font_family）与首页一致
- 不一致时发出警告（warning），不中断（容错）
- 提取 `_load_or_create_lock()` 的读取逻辑为 `_read_lock(project)` 独立函数

**Verification:** 测试多页生成时每页读取 spec_lock、值不一致时警告

### Task 8: IDE 规则文件同步 [DG-01]

**Files:** `.cursorrules`, `.windsurfrules`, `.github/copilot-instructions.md` (modify)

**What:**
- 各规则文件新增八确认门控说明（简化版）
- 指示 agent 在生成 PPT 前先确认用户意图

**Verification:** 各文件包含确认门控相关内容

## Execution Order

```
Task 1 (confirmations.py) → Task 2 (CLI) → Task 3 (门控集成)
Task 5 (design_spec) → Task 6 (spec_lock) → Task 7 (逐页重读)
Task 4 (SKILL.md) → Task 8 (IDE rules)
```

Wave 1 (parallel): Tasks 1, 5, 6
Wave 2 (depends on Wave 1): Tasks 2, 3, 7
Wave 3 (depends on Wave 2): Tasks 4, 8

## Success Criteria

1. `slide-skill confirm <project>` 写入确认项，`slide-skill check-confirm <project>` 验证完整性
2. `generate_svg()` 在无 `confirmations.json` 时拒绝执行（除非 `--skip-confirm`）
3. `design_spec.md` 包含 audience、objective、per-page key_message 和 design_rationale
4. `spec_lock.json` 新增 audience、objective、per_page_rationale 字段
5. 竞赛模板自动填充赛制要求到 design_spec
6. 逐页循环前重读 spec_lock，值不一致时警告
7. SKILL.md 包含 Design Gate 章节和八确认指示
8. 所有 144+ 现有测试仍通过
