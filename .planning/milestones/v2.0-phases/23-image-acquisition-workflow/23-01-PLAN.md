# Phase 23: Image Acquisition Workflow — Plan

## Goal

实现图片搜索、AI 生成、许可过滤和自动引用，使演示不再缺图

## Requirements Covered

IMG-01, IMG-02, IMG-03, IMG-04, IMG-05

## Tasks

### Task 1: 图片搜索模块 — image_search.py [IMG-01, IMG-02, IMG-04]

**Files:** `tools/slide/src/slide_skill/image_search.py` (new)

**What:**
- `search_images(query, limit=5, license_filter="permissive")` → 搜索 CC 许可图片
- 使用 Creative Commons API (api.creativecommons.org) 作为首选后端
- 许可过滤：默认仅 CC BY / CC BY-SA / CC0，拒绝 NC/ND
- `download_image(url, dest_dir, filename)` → 下载图片到 `images/`
- `_extract_dominant_color(image_path)` → 用 Pillow 提取主色
- `_build_metadata(filename, source, query, license, dimensions, dominant_color)` → 构建元数据
- 依赖：`requests`（已有 intake 可选依赖），`Pillow`（已有核心依赖）

**Verification:** 单元测试覆盖搜索、下载、许可过滤、元数据生成

### Task 2: AI 图像生成模块 — image_generate.py [IMG-03, IMG-04]

**Files:** `tools/slide/src/slide_skill/image_generate.py` (new)

**What:**
- `generate_image(prompt, dest_dir, size="1024x1024", backend="openai")` → 调用 AI API 生成图片
- 使用 `openai` 库的 `images.generate`（DALL-E 3）
- 环境变量：`IMAGE_API_KEY`（默认从 OPENAI_API_KEY 继承）
- 环境变量：`IMAGE_BACKEND`（默认 "openai"）
- 生成后提取主色，写入元数据
- 无 API key 时给出明确错误提示

**Verification:** 单元测试覆盖 API 调用、错误处理、元数据生成

### Task 3: 元数据管理 — image_meta.py [IMG-04]

**Files:** `tools/slide/src/slide_skill/image_meta.py` (new)

**What:**
- `load_metadata(project_path)` → 读取 `images/metadata.json`
- `save_metadata(project_path, metadata)` → 写入 `images/metadata.json`
- `add_image_metadata(project_path, entry)` → 追加单条图片元数据
- `list_images(project_path)` → 列出所有已索引图片
- 向后兼容：metadata.json 不存在时返回空结构

**Verification:** 单元测试覆盖读写、追加、空项目

### Task 4: CLI 命令 [IMG-01, IMG-02, IMG-03]

**Files:** `tools/slide/src/slide_skill/cli.py` (modify)

**What:**
- `image-search` 子命令：`slide-skill image-search <project> --query <query> --limit 5 --allow-nc`
- `image-generate` 子命令：`slide-skill image-generate <project> --prompt <prompt> --size 1024x1024`
- `image-list` 子命令：`slide-skill image-list <project>` 列出已索引图片
- 新增 `image` 可选依赖组：`[image]` = requests + openai

**Verification:** CLI 集成测试

### Task 5: SVG 自动引用 images/ [IMG-05]

**Files:** `tools/slide/src/slide_skill/svg_pipeline.py` (modify)

**What:**
- spec_lock.json 新增 `resources` 字段：图片资源列表 `["img_001.jpg", "img_002.png", ...]`
- `create_spec()` 从 `images/metadata.json` 读取可用图片，填入 spec_lock.resources
- `generate_svg()` 中 image 布局类型自动从 spec_lock.resources 匹配图片
- 匹配逻辑：按 resources 顺序分配给 image 布局的幻灯片，超出时循环
- `_render_slide_svg()` 中 image 布局使用匹配的图片路径替代占位符

**Verification:** 测试有图片资源时 SVG 引用正确路径

### Task 6: SKILL.md 和 IDE 规则更新

**What:**

**Verification:** 文件包含图片获取相关内容
