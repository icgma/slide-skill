## Goal

Promote slide-skill from "good text decks" to "rich visual decks" — native charts, icons, code, element-level animations, presenter-grade preview, first-class PDF export, theme plugin ecosystem, and multi-language template coverage.

---

## Phase Order Rationale

Phase 18 lands the plugin contract first because every later phase touches `ThemeSpec` or registers a new asset kind. Phases 19-21 are independent visual primitives (icons / code / charts). Phase 22 extends the existing PPTX animation serializer. Phases 23-24 build on the now-richer SVG output. Phase 25 closes the milestone with examples that exercise everything above.

## Phases

### Phase 18: Theme Plugin System (entry-points + user TOML)

**Status:** Shipped | **Commit:** 4f8eb8a | **Tests:** 7

- Promoted `ThemeSpec` to a registry keyed by entry-point group `slide_skill.themes`.
- Added `slide theme add <path-or-name>`, `slide theme list`, `slide theme remove`.
- Discover external packages installed via `pip install slide-theme-foo`.
- Local `./mytheme.toml` install path: copies into `~/.config/slide-skill/themes/` and registers.
- All 5 built-in themes migrated to entry-points without behaviour change.

### Phase 19: Icon Library (Lucide subset + theme stroke)

**Status:** Shipped | **Commit:** 75f5a2e | **Tests:** 8

- Vendored curated subset of Lucide (~200) and Tabler (~150) as inline SVG.
- Spec syntax: `icon: rocket` / `icon: lucide:rocket` / `icon: tabler:flame`.
- SVG pipeline injects `<svg>` symbol references; PPTX exporter rasterizes to EMF.
- Theme can override icon stroke colour and weight.

### Phase 20: Code Block Highlighting (Pygments → SVG)

**Status:** Shipped | **Commit:** 11070a2 | **Tests:** 8

- Detect fenced code blocks in source markdown with optional language hint.
- Render via Pygments to SVG using theme-mapped style.
- Layout `code` slot supports `lines: true` and `highlight: [3, 7-9]`.
- PPTX exporter embeds rendered SVG as Picture shape with alt-text for accessibility.

### Phase 21: Native Charts (matplotlib SVG + c:chart)

**Status:** Shipped | **Commit:** 32dcfa4 | **Tests:** 7

- Spec declares charts inline (bar, line, pie, area, scatter).
- SVG render path: matplotlib (Agg → SVG) styled by theme palette.
- PPTX render path: native DrawingML `c:chart` part with embedded `xlsx` workbook.
- Round-trip test verified.

### Phase 22: Element Animations v2 (build order + triggers)

**Status:** Shipped | **Commit:** 81c7aee | **Tests:** 11

- Extended slide-transition support to per-element animations.
- Effects: fadeIn, fadeOut, slideIn, zoomIn, zoomOut, pulse, wipe.
- Build order (`order: N`) controls click-through sequence.
- Serialized to PPTX `<p:timing>` tree.

### Phase 23: First-Class PDF Export (slide pdf + cairo)

**Status:** Shipped | **Commit:** 509324a | **Tests:** 5

- New `slide pdf <input>` subcommand.
- Default backend: LibreOffice headless; optional `--backend=cairo`.
- `--quality=draft|standard|print` tunes raster DPI.
- Notes appended as PDF page-level annotations.

### Phase 24: HTML/Reveal Preview + Presenter View

**Status:** Shipped | **Commit:** 2eb48d5 | **Tests:** 6

- Flask demo `/preview/<job_id>/html` route renders Reveal.js-style deck.
- Presenter mode: split window with current + next slide + notes + timer.
- Hotkeys: B blackout, W whiteout, F fullscreen, ←/→ nav, Esc exit.

### Phase 25: Multi-Language Templates + Font Preflight

**Status:** Shipped | **Commit:** (same as milestone close) | **Tests:** 16

- Shipped `examples/i18n/` with 15 example decks: 5 themes × {zh-CN, en, ja}.
- New `slide doctor --fonts <theme> <lang>` subcommand.
- Documentation: `docs/i18n.md`.
